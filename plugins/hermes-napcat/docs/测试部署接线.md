## 正式宿主 API 与实际接线

[官方 Plugin LLM Access](https://hermes-agent.nousresearch.com/docs/developer-guide/plugin-llm-access) 明确支持 gateway adapter 的 `ctx.llm.acomplete`，使用用户当前 model/auth，提供单次 completion 和覆盖参数的 trust gate。本实现不传 provider、model、profile、agent_id 或 task 覆盖，不复制 OAuth／auth.json，不建立私人 AIAgent／MemoryManager，不调用工具循环。宿主仍管理其模型客户端的认证、网络及内部重试策略；插件不另加重试。辅助 OpenRouter 图片请求另有固定 endpoint 与单次请求策略。

核对的宿主源码 HEAD 为 `5894e750c3dba980d43b25aa29e3958149ba2c61`。相关正式入口是 `hermes_cli/plugins.py:PluginContext.llm/register_platform/on_unload`、`agent/plugin_llm.py:PluginLlm.acomplete`、`gateway/platforms/base.py:handle_message/on_processing_start/on_processing_complete` 和 `hermes_constants.py` 的 home ContextVar 接口。没有修改宿主源码，也无需候选宿主补丁。版本号不能单独证明接线：factory检查实际 facade 类型／方法签名与 lifecycle hooks，connect 在创建唯一 OneBotClient 前执行真实 sandbox probe，每轮执行前后再次校验 home、域、revision 和 worker 合同。

普通 `register(ctx)` 注册闭包 factory；只有显式 `extra.runtime.mode=host_llm`、`contract=4` 才构建 `HostedNapCatAdapter` 与 `HostIsolationBridge`。无 runtime 的旧文本配置保持原行为；strict 没有已绑定 bridge 仍拒绝连接。此 factory 仅支持允许群和精确主人 DM，`guest_dm_users` 必须为空，访客私聊拒绝。显式group_admission=all_members开放白名单群真实成员；缺公共合同1的旧含记忆bridge拒绝。所有群消息，包括主人发言，只进入公共单次调用，不经过 native handler。

worker 保留独立 namespace、无网络、清空环境和 ProcessOwner 取消回收。host 模式只读挂载专用目录内的 `scoped-memory.json` 文件和插件源码，连整个社交目录也不挂载；没有主人 home、凭据、历史或私人内存。`host_contract=4` 分支在记忆／旧模型分支之前返回，只接受闭合的 prepare 合同、绑定当前route的公共身份及受限附件，返回本轮 JSON 的 digest；旧3或未知host合同拒绝，不回落记忆路径。宿主只核对 digest，再自行构造固定 system 和本轮公共身份／问题／不可信附件；worker 无权指定 messages、model、target 或工具。该模式无长期记忆和跨轮历史，不能把旧 local-memory worker 的能力当成本模式已启用。

宿主 facade 调用运行在新的 asyncio Context，并显式清空私人 session/profile/history/cwd，固定到注册时的 home 来使用该 profile 的模型认证。调用前后检查注册绑定；卸载立即使其失效。并发 profile 不共享 session Context。文本／媒体模型分别有两个活动槽位，外层保留18项文本、18项媒体、8项取消控制及既有超时；有限队列不承诺可靠送达。

主人 DM 调用原 `BasePlatformAdapter.handle_message` 和原 handler，保留原 agent／工具／记忆。handle_message 接受入队后可以立即返回，所以入口短期 permit 仅负责同步／inline 回复；后台 `on_processing_start` 新建独立 permit，`on_processing_complete` 在实际发送结束后撤销。共享 active 位拒绝复制上下文的迟到回复，disconnect／unload 也拒绝后续发送。目标只能是精确主人 DM；回复锚点须来自当前有界准入账本（64项、900秒），不开放任意群发送。

## 名称触发与费用模式

`extra.group_trigger: {mode: name_or_mention, name: 示例呼唤名}` 允许原始 text segment 含字面名字，或真实 at segment 指向机器人。依然要求账号、群和机器人身份全部通过 ACL。昵称／名片、群名、附件、引用正文及伪 CQ token 中的名字不能唤醒；不递归查询引用来判断唤醒。前缀称呼会去掉，以支持 `示例呼唤名 /media file` 和 `示例呼唤名 /media cancel <id>`；同条附件和单层引用均走原媒体路径。未配置 group_trigger 时沿用 require_mention；strict 不接受 legacy 全消息开放。

`media.budget_mode` 默认 `local`，云调用仍要求四项完整预算配置。只有显式 `provider` 才跳过本地调用数／美元账本，不创建预算数据库；混用本地预算字段会报错。provider 模式不改变 ACL、并发、字节、附件、超时、出站许可和无自动重试。供应商 key 的额度由部署者核实，本地不声称已生效。辅助图片固定 `qwen/qwen3-vl-30b-a3b-instruct`，本阶段不启用语音。

辅助 provider 主读取 `OPENROUTER_API_KEY`。仅当这个变量**不存在**时兼容 `NAPCAT_MEDIA_OPENROUTER_API_KEY`；标准变量存在但为空／非法时直接拒绝，不悄悄切换计费 key。解析器和 prepare worker 不接收两种 key。OneBot 独用 `NAPCAT_ACCESS_TOKEN`。清单将标准变量列为 optional，关闭云功能不要求它。

## 父任务需要准备的材料

1. 审阅并分发本插件全部源码（包括 `host_runtime.py`、媒体模块和 `process_owner.py`），以及匹配的兄弟 `hermes-scoped-memory/isolated_worker.py`。`stage_install.py` 只生成新的非活动目录候选，不会安装；兄弟 worker 需要父任务另外按同版源码分发。
2. 建立父任务选择的专用绝对路径，owner-only 0700，不能是主人 home／其祖先或子目录，也不能含 `.hermes` 或软链接。目录只能有 `scoped-memory.json`，内容按 [JSON模板](../examples/scoped-memory.host-test.json) 修改域和 revision，并与隔离策略一致。不放 `.env`、auth.json、model.key、chat.json 或 mem0.json。
3. 按 [关闭状态配置模板](../examples/config.host-test.disabled.yaml) 合并配置。号码全是占位；真实账号／群 ACL、social_home、下载策略或专用 export 均由父任务填写与审核。模板默认平台关闭、插件列表为空，不能直接连接；示例显式 `public_https` 并省略 hosts，仍受 HTTPS／443、TLS、公网DNS／SSRF和解析限制。旧默认 `allowlist` 空hosts拒绝下载。取消域名过滤不等于没有网络／解析风险；详见 [下载迁移](媒体实现与验收.md#下载策略与配置迁移)。不要覆盖原配置或另起第二个 OneBot 接收器。
4. 使用已有已审核 bwrap／ffmpeg／文件解析依赖，确认用户 namespace 可用、宿主 API 兼容、网关进程可读取标准 OpenRouter key 与 OneBot token。任务文件称父任务已将同一标准 key 写入受保护环境文件；本轮没有读取凭据值，也没有确认网关已加载它。现无需另复制专用 key；若进程未继承，父任务负责修复可见性。
5. 父任务审阅后才部署、启用并检查真实 QQ：名称／真实@、图片中文、文件引用和选择、普通文本、主人私聊记忆与工具保留、群无私人上下文、撤回／取消、迟到回复和费用。真实云可用性、provider ZDR／数据策略、CDN、容器映射及图像质量都尚未验收。主模型与辅助图片分别计费，provider 模式没有本地费用兜底。
