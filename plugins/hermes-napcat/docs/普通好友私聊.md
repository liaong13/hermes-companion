# 普通 QQ 好友受限私聊

版本 `0.6.0`。本功能把普通好友的私聊接入社交域，精确主人私聊继续使用原私人域。源码与合成测试不代表已安装、重载或真实 QQ 验收。

## 显式配置与身份

配置位于 `platforms.napcat.extra.friend_dm`：

```yaml
friend_dm:
  enabled: true
  admission: explicit
  users: ["77777"]
  allow_group_members: false
  media: false
```

号码为合成占位。`admission=explicit` 允许 `users` 指定的账号；`allow_group_members=true` 另行允许当前 `allowed_groups` 中实际成员的普通好友。`verified_friends` 则允许真实好友名单中经核验的普通好友。所有路径都要求 OneBot 当前 `get_friend_list` 成功证明好友资格，不能只凭 incoming `sub_type=friend`、昵称或用户自述。`enabled`、`allow_group_members`、`media` 默认关闭。新 `users` 独立于 `allowed_users`，不能为了好友社交把所有好友导入主人原生入口白名单。

群友范围只查询既有允许群的 `get_group_member_info(group_id,user_id,no_cache=true)`，响应中的群号和本人账号必须同时匹配；私聊消息携带的 `group_id` 不授予权限。正证据缓存 30 秒，失败缓存 5 秒；每次发送前重新核验，离群、撤掉群范围、失去好友资格或断线会撤销资格。群成员查询资料不进入 LLM，不把群好友自动加入主动私聊目标；临时会话仍不进入普通好友路径。安装器以 `--friend-group-members` 显式开启这个范围。

成员查询按同一官方固定版本的 [GetGroupMemberInfo](https://github.com/NapNeko/NapCatQQ/blob/98d781d19815d1625b24d717ce280ecf0a4f6d0c/packages/napcat-onebot/action/group/GetGroupMemberInfo.ts) 发送字符串群号、账号与布尔 `no_cache`；回包按 [OB11GroupMemberSchema](https://github.com/NapNeko/NapCatQQ/blob/98d781d19815d1625b24d717ce280ecf0a4f6d0c/packages/napcat-onebot/action/schemas.ts) 的 `group_id`、`user_id` 核对。2026-11-01 复核该 API 的源码合同，不把客户端参数当成员证据。

旧 `isolation.guest_dm_users` 在标准工厂中作为显式名单兼容；该旧字段仍遵守既有 `allowed_users` 子集约束。未配置 `friend_dm` 时，非空旧名单提供明确启用意图；显式 `enabled:false` 可以停用。完全没有配置和旧名单时不会扩大准入。

好友名单查询最多等待两秒，成功缓存五分钟，失败清除好友证据并限速重试。每次真实回复发送前再次强制核验，好友被删除、资格失效、配置停用或连接变化均禁止迟到回复。不能为弥补失败切到主人 agent。

## 对话与媒体

普通好友的文本走独立的正式 `ctx.llm` facade，使用空 Context、当前 profile 的既有模型及明确的本好友资料；不提供工具，不加载 SOUL、USER、MEMORY、主人或其他群／好友历史。昵称仅取当前 QQ 显示昵称，不使用机器人主人设置的好友备注。

每位好友临时保留最近十分钟、最多十二条实际交流；输入资料总预算 32000 UTF-8 bytes，先淘汰旧背景，仍超限则报告预算限制。接话接入 social 的 `observe`、临时公开上下文和公开风格；成功发送并对私聊消息 ID、机器人作者、精确收件人及原文回读后才 `record_self`。回执不明或回读不符不重发、不记作已核验交流。

2026-10-31 核对 NapCat 官方源码 commit `98d781d19815d1625b24d717ce280ecf0a4f6d0c` 的 [GetMsg schema](https://github.com/NapNeko/NapCatQQ/blob/98d781d19815d1625b24d717ce280ecf0a4f6d0c/packages/napcat-onebot/action/msg/GetMsg.ts) 与 [initializeMessage](https://github.com/NapNeko/NapCatQQ/blob/98d781d19815d1625b24d717ce280ecf0a4f6d0c/packages/napcat-onebot/api/msg.ts#L1140)：标准私聊回读不包含 `target_id`。本实现用本次精确目标的真实 `send_private_msg(user_id)` RPC／唯一 ACK 证明发送对象，再核对 `get_msg` 的 ID、private 类型、机器人作者及原文；若 `target_id` 存在却冲突则拒绝。只有全部通过后才登记最多 512 条、30 分钟的内存发送证据（消息 ID、目标与原文 SHA-256，不保存正文）；现存账本中的 ACK ID 不能由另一轮发送重复登记到相同或其他好友。后续按 ID 读取机器人私聊时，缺少明确目标字段必须匹配这份已核验账本；未知 ACK、其他好友、原文不符或新实例缺账本都不能借此读取旧私聊。不会扫私聊历史来猜对象。

`friend_dm.media=true` 只是额外准入条件，仍需原 `media.enabled/types/cloud/allow_derived_text` 全部允许。文件、图片与语音复用已有下载校验、解析沙箱和 provider，不开放主机路径、任意 URL 或新下载协议。当前好友随消息发送的资料、可核验的同好友原消息和同域短期媒体候选可以处理；跨好友／群引用被拒绝。私聊文件句柄使用官方 [`get_private_file_url`](https://napneko.github.io/onebot/api) 取得下载 URL，失败时不退回可携带任意 base64／路径的通用下载接口。

同一固定版本的 [GetPrivateFileUrl](https://github.com/NapNeko/NapCatQQ/blob/98d781d19815d1625b24d717ce280ecf0a4f6d0c/packages/napcat-onebot/action/file/GetPrivateFileUrl.ts) 仅接收真实消息中的 `file_id`；不由模型构造文件句柄。

当前配置提供的群中媒体权限不会自动授权好友媒体云处理；明确启用好友媒体时才沿用已选模态与云处理范围。主人私人 DM 的媒体路由不受本机制改写。

## 主动联系、读取旧话题与遗忘

ParticipationPort 提供 `friend_dm_enabled`、`public_dm_users`、`dm_allowed` 和 `dm_target_allowed`。静态目标配置不等于好友资格；实际读取、claim 和发送仍须在运行时核验。受限好友 DM 的主动目标必须单独列出，不能从所有好友自动生成主动发送对象。

一般活动的 `send_activity` 使用同一个精确目标 grant、消费回调和准确回读，与模型 idle／约定共用 social 的预算。该端口不将一般活动冒充本人确认的约定；活动来源、有效期、claim／finish 和反馈由生活协调层负责。

`read_dialogue_refs(chat, message_ids)` 只读取协调层已登记的最多八个精确消息引用，不扫历史。群消息必须提供完整群来源；好友消息必须提供对应私聊作者／收件人证据。返回纯文本、当前公开名字与回复关系，不下载附件，也不提供原 source 作为发送权限。跨场所、撤回、未知类型和权限变化返回空。

`forget_dialogue_refs` 会撤销精确来源并清理好友临时历史，阻止后续回合重新引用被忘记资料。断线、卸载和好友撤回取消在途任务。P4 激活的 `reply_char_limit(chat)` 只约束群及普通好友社交回复，按字符上限优先保留完整句；不裁剪主人私人回复和本地控制结果。

## 当前验证

`tests/test_friend_dm.py` 使用真实 SDK facade 和捕获端，当前 41 项专项通过，包含好友核验、白名单群成员资格与离群竞态、同名／备注隔离、主人原路径、两好友上下文、短期续聊、删除好友／撤回／断线竞争、私聊文件和图片、跨好友引用拒绝、单次主动联系、阅读精确引用、遗忘、公开长度策略及缺少目标字段的发送回读证据。多数 transport fixture 显式模拟 direct-dialogue 分类结果；另有一项使用真实 social 分类器、话题框架及正文链的整合测试。模型语义质量仍由真实模型整合验收负责。

`integration/hermes-host/verify_friend_dm_live.py --live --host ... --owner-home ...` 使用真实 `PluginContext.llm` 分类及正文，只有名单、消息与 OneBot 收发为合成捕获端；独立检查同名好友隔离、短答续聊、隐私拒绝、群成员好友、未列名单／非好友及主人原路由，报告真实 provider/model、实际入模文本、无工具 wire 和 exact-source 证据。该脚本禁止建立 OneBot 连接，不等于真实 QQ 客户端验收；不验证媒体模型语义。

2026-11-01 配套全套 NapCat 回归共 398 项，16 项因既有前提缺失跳过，其余通过；普通好友真实模型捕获 8 项通过，使用 openai-codex / gpt-6-luna，10 次实际无工具请求、零次真实 OneBot 连接。完整套件仍有既有日志 handler／SQLite 资源警告，本组件没有把它们当作新功能验收。部署及真实 QQ 状态见[本阶段记录](../../../docs/连续社交阅读与反馈实现.md)。
