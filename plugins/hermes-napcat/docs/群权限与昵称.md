# 群权限分层与昵称接线

2026-10-27 源码实施阶段，自有内容 MIT。本阶段未改生产、宿主、凭据或网关；此前名称触发已由用户验证，引用图现场失败经只读诊断定位为原作者不在 allowed_users。新的普通群友准入及昵称输出仍待父任务独立复核和 QQ 验收。

## 权限表

| 场所／身份 | 准入与触发 | 资料和能力 | 记忆归属 |
| --- | --- | --- | --- |
| 主人精确好友DM | 数字owner_id且在allowed_users | 原native handler、工具及生命周期reply permit | 原私人域保持 |
| 普通成员DM | 本次host_llm factory拒绝，包括在allowed_users中的非主人 | 无 | 无 |
| 白名单群主人 | 经认证事件身份，名称或真实@ | 公共单次文本、启用的图片／文件；管理转主人私聊 | 不加载私人SOUL／MEMORY／USER，无长期记忆 |
| 白名单群普通成员 | 默认须在allowed_users；显式all_members后不受该清单限制，仍核验真实ID与sender一致 | 与主人群内相同，无主机命令、系统管理、密钥／配置／私人文件或跨群／他人DM能力 | 无长期记忆，不表示群友记忆管理上线 |
| 同群显式引用的第三人 | 新策略允许非请求者及非DM准入作者 | 核验group/message ID、canonical作者、sender一致及非机器人；只取单层正文／附件 | 仅本轮不可信引用 |
| 背景媒体 | 不唤醒，不下载、不调用模型 | 可选有界元数据；“刚发的”／/media选择仍只查请求者本人候选 | 内存TTL，撤回失效 |
| 其他群、伪造／不一致来源、自发机器人 | 拒绝 | 无 | 无 |

场所、数字身份、owner/member角色、触发、资料可见性、能力授权和记忆归属分别校验。群管理员、昵称叫“主人”、与主人同名或允许DM都不会提升角色。真实身份依赖已认证 OneBot 连接；NapCat/token本身在信任域，插件不能独立证明协议服务器没有伪造用户。

## 配置与迁移

`extra.group_admission` 仅接受 `allowed_users`（缺省，旧语义）和 `all_members`。后者必须 strict，且代码绑定的bridge提供 `public_group_contract=1`。当前只有 prepare-only `HostIsolationBridge` 提供它；旧 `ProcessIsolationBridge` 的含记忆worker不可用于新开放策略。缺有效bridge、probe失败或合同不符均fail closed，不回落native。

在既有经过审核的host配置上，由父任务合并以下最小增量，不替换真实号码或扩大allowed_groups／allowed_users：

```yaml
# platforms.napcat.extra 内
group_admission: all_members
isolation:
  policy_revision: 2 # 示例；实际使用高于当前值的新正整数，保留原其他字段
runtime:
  contract: 4 # 保留原mode和social_home
```

同一专用 `scoped-memory.json` 的 `policy_revision` 必须同步，并将 `host_contract` 改为4；仍只保留schema_version／mode／domain_id／policy_revision／host_contract五个字段。插件、兄弟 `hermes-scoped-memory/isolated_worker.py` 和配置须同批匹配。旧合同3会被拒绝，不能混版更新；未声明host合同的旧隔离worker路径保留。关闭模板示例见 [YAML](../examples/config.host-test.disabled.yaml) 和 [JSON](../examples/scoped-memory.host-test.json)。

媒体仍须显式enabled、groups（allowed_groups子集）、types、references、observe_metadata、allow_derived_text及精确下载来源授权。图片固定Qwen3-VL，标准OPENROUTER_API_KEY和provider预算模式保持；语音关闭，不装Whisper。可只启用文本社交而不启用媒体。

## 昵称和引用合同

群名片card优先、同一事件QQ nickname次之，缺失回退“群友”；不查好友备注、私人档案或已知真名。拒绝过长、控制字符及角色／指令形状的显示值，安全回退。显示值是JSON user数据，固定公共system只要求按当前群昵称称呼所有人（包括主人）、不推测真名；system不做昵称模板插值。public_identity包含platform／user_id／chat_id／role／display_name，由worker合同4校验并纳入digest。名称不是授权，改名不改权限，同昵称账号保持独立数字身份和scope。

单层显式引用可跨作者但不能跨群、来自私聊、歧义、多重reply或已撤回来源；只读取核验消息的原始text与已启用附件，不递归引用／转发。引用文字以text类不可信附件交给公共facade，不成为指令。默认旧作者准入仍保留；新策略的同群第三人资料权限不会扩大模糊选择范围。接收时冻结候选，执行时复核scope／TTL／当前策略，撤回及取消维持既有独立控制槽与ProcessOwner回收。
