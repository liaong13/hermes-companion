# 共享人格与日常记忆

同一智能体可以在群里保持与私人 Hermes 相同的人格，也可以接续与主人及朋友发生的非敏感日常经历。明确托付的秘密仍须保守；没有说“保密”不意味着敏感个人资料可以公开。

## 启用与来源

使用仓库根目录的统一安装器：`--share-persona` 仅共享人格，`--share-daily-memory` 同时启用日常记忆。默认只输出计划；安装和激活分别使用 `--apply`、`--restart`。旧配置默认不启用，升级保留已有选择。配置位于 `platforms.napcat.extra.shared_identity`：

```yaml
shared_identity:
  enabled: true
  daily_memory: true
```

只支持 `social_agent / contract: 5`。正常点名、自然接话和已授权的群空闲开口使用同一来源；主人私人原生回合保留。普通好友受限私聊暂不使用此共享视图。

- `SOUL.md`：直接从当前通道绑定的 profile 读取，作为身份、价值取向和声线。公开自述只作补充。SOUL 应保存人格，不应作为秘密、账号或私人档案存储；其中路径和工具描述不能授予群权限。
- `memories/MEMORY.md`、`memories/USER.md`：固定来源，只由私密侧无工具模型读取。选择智能体自身及与主人、朋友的非敏感日常，保留主体、来源及必要时间，匿名描述人物。
- 不导入私人会话数据库、CLI 历史、其他群记录或外部 provider；不修改或替换既有 `memory.provider`，不增加对话采集。

## 筛选与失效

每轮私密侧先提取最多六条有连续原文证据的短摘要，再独立审核隐私、主体与依据。保密托付约束同一件事的其他表述、概括和暗示，不能只删除“保密”二字后转述。凭据、身份资料、联系方式、精确位置、健康、财务、工作机密和私密关系排除；不确定时不选。确定性检查还会拒绝敏感证据段落、路径注入、越界文件来源、无原文证据和无效审核返回。

群模型只得到 SOUL 与通过审核的匿名摘要，不得到 MEMORY/USER 原文、引用证据或保密清单。筛选不使用群正文、群成员自报身份、工具或继承的会话 Context。只调用当前 profile 已有模型，至多增加两次请求，不在日志记录原文或模型输出。

共享模式强制新建群 Agent 并跳过宿主旧历史；近期同群资料仍由既有通道提供。人格、记忆文件、来源许可、连接或策略变化后，已准备视图失效，工具及最终发送再次核验。审核失败时保留人格、舍弃日常记忆；人格文件缺失、无效或来源过期时拒绝该回合。固定路径拒绝符号链接、非当前用户文件、可由其他用户改写的文件及超预算内容。

语义筛选和独立审核不能证明绝对不泄露；SOUL 自身仍是群模型可见的身份文本。现有同群资料及好友记忆仍遵循各自权限，不因该选项获得跨群原文检索权。已发送内容无法通过删除本地记忆撤回，模型服务的记录也不由本功能删除。

## 验证

新增离线回归使用合成 profile、模型响应及 QQ 出站端，覆盖同源 SOUL、双重审核、秘密证据拒绝、审核失败、文件删除／修改、来源撤权、工具与回复许可，以及空闲开口的同源人格。宿主组合检查覆盖新旧补丁堆栈与重复安装。离线通过不代表真实模型判断或 QQ 客户端效果已经验收。

`integration/hermes-host/verify_shared_identity_live.py --live --host /path/to/hermes-agent --owner-home /path/to/profile` 只读解析既有模型认证，使用临时 profile 的合成人格、日常和秘密测试真实筛选、审核及公开回复。它不读取真实用户记忆、不连接 QQ；凭据仅保留在进程内。可加 `--show-synthetic` 查看合成场景的 JSON 诊断，不能把这项通过称作真实 QQ 验收。

2026-11-01 的源码验证：新增共享人格回归 16 项通过；宿主公开提示词与本地历史隔离回归 12 项通过。真实既有模型的合成筛选、独立审核及公开回复三次调用通过：同源人格保留、普通日常可接续、合成秘密及敏感资料未进入公开回复。首次真实模型探针发现审核把私密侧证据也作为对外内容判断，修正后明确仅审核公开摘要，原文证据留在私密侧；这些样本不证明任意秘密都不会泄露。
