## 历史测试覆盖与未验收边界

- 已验证：提供者路由、身份／来源边界、CRUD 越权防护、并发和持久性、来源归档、TTL、替换、关键词／一跳关联及字节预算。
- 未验证：真实云端调用、新插件的真实 QQ 端到端运行、自动 LLM 提取、向量／混合检索、生产故障恢复。
- 插件不是 agent／操作系统沙箱。内置注入、缓存提示词、终端／文件／历史／技能、共享群会话及模型出站仍需宿主约束；`isolation_reviewed` 不能代替这些约束。
- 目前关键记忆需要明确工具写入，不是自动语义提取。中文相邻双字与关联查询不是向量搜索。
- 自动召回预算实际按 UTF-8 字节，不是精确 token；显式工具读取有独立限额。
- 原文是宿主脱敏后交给提供者的本轮 user／assistant 字符串，不含原消息包、附件或工具轨迹。
- 内存队列崩溃可丢未刷盘项目；软删除不等于彻底擦除，原文保留管理是独立机制。

完整行为与启用门槛见 [README](../README.md)，当前事实见 [开发状态](开发状态.md)，待评估方案见 [开发设计](开发设计.md)。
