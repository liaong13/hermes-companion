## 研究给出的实际方向

### 斯坦福小镇：把观察、反思和规划连接起来

[Generative Agents，UIST 2023](https://arxiv.org/abs/2304.03442)展示了 25 个角色在小镇中的行为。关键机制是持续记录观察、按相关性／时效／重要性召回、从经历提炼反思，再把计划分解为具体行动。[作者代码](https://github.com/joonspk-research/generative_agents)提供对应模块。

本项目借鉴“经历影响下一次选择”的循环。小镇的地图、角色可知信息和行动效果由模拟环境定义；移到互联网后，要由通道事件、网页读取结果和实际执行回执提供这些事实。不能让模型写一句“我读过了”就完成一次阅读。

### Anuttacon：区分公司产品、角色表演和生活架构

[Anuttacon 官网](https://www.anuttacon.com/about/)提出多模态交互与虚拟世界方向；[Whispers from the Star 官方说明](https://wfts.anuttacon.com/)描述专有模型／管线支持角色驱动的对话、情绪记忆和适应性回应。这些资料说明产品追求，未公开其完整记忆、规划和自主活动实现，不能反推出内部架构。

[LPM 1.0，2026](https://arxiv.org/abs/2604.07823)研究说话、倾听、反应及长期视觉身份稳定；作者的[项目经历说明](https://liyuwei.cc/)将其列为 Anuttacon 项目。论文[局限与后续工作](https://arxiv.org/html/2604.07823v2#S7)明确将长程对话记忆、多方协调和环境行为列为需要继续研究的方向。它适合后期表达层参考，不能承担本项目的生活规划器。公开的[项目页仓库](https://github.com/large-performance-model/large-performance-model.github.io)是演示前端；本次没有验证可用的模型权重、推理代码或 API，不将其列为可安装依赖。

### Agentopia：长期活动和社会经验

[Agentopia，2026](https://arxiv.org/abs/2606.07513)研究 100 个 Agent 在十个模拟年中的生活与基于轨迹的训练。[论文署名](https://arxiv.org/html/2606.07513v1)为复旦大学、其他院校和独立研究者，未署 Anuttacon；本文将它列为相关研究，不称为 Anuttacon 官方开源产品。

值得借鉴的是计划、联系、活动、回顾的阶段组织，以及人物笔记和状态恢复。其环境模型可以生成事件与活动结果，生活奖励也属于模拟环境；真实互联网应使用可核对结果，并将模拟记录单独保存。论文同样讨论了回合制、幻觉、奖励对齐和计算成本的限制。本项目暂不进行模型权重训练，也不把模拟社交回报当真实关系质量。

用户补充的[中文 README](https://github.com/Neph0s/Agentopia/blob/da264aa6d82cca98f2051bcf794ff5dd98f10fdb/docs/README.zh.md)也已核对。当前实现先借鉴人物笔记的结构，为每条资料补上可信主体、证据、使用场所与撤销；阶段循环与 checkpoint 留给后续活动层。首个切片复用本仓库 Store，自行实现接线，未复制该项目代码。

补充区分：论文第 4.2 节的生活奖励训练采用轨迹筛选并微调底层模型，不能等同于在线写入记忆。当前借鉴重点调整为先接通经验回用与计划，不以额外的回复关键词模拟学习；原“阶段循环留给后续”的切片顺序由最新开发方案修订。

## Hermes 官方资料与本地代码的优先级

已核对官方[插件开发](https://hermes-agent.nousresearch.com/docs/developer-guide/plugins)、[Cron](https://hermes-agent.nousresearch.com/docs/user-guide/features/cron)、[持久目标](https://hermes-agent.nousresearch.com/docs/user-guide/features/goals)、[Heartbeat](https://hermes-agent.nousresearch.com/docs/user-guide/features/heartbeat)、[Loops](https://hermes-agent.nousresearch.com/docs/user-guide/features/loops)和[Bot Mode](https://hermes-agent.nousresearch.com/docs/user-guide/bot-mode)。它们提供插件、执行、唤醒与任务管理入口，不等于已经交付个人生活模型。

当前安装的代码和配置仍是部署判断依据，见[本地能力核对](本地Hermes能力核对.md)。尤其本地 skill 的旧后台说明称 cron 默认跳过记忆，但当前 `cron/scheduler.py:_construct_cron_agent` 明确设置 `load_soul_identity=True`、`skip_memory=False`。方案不能依据旧说明把私人 default 的 cron 当成无私人上下文的执行器。

## 移植结论

优先自行实现最小的经历／人物数据合同，复用现有 scoped-memory 的来源、删除、事务与检索机制，再为 social 增加有限的读取入口。生活层后续只增加关注事项、活动状态和反馈选择；执行、调度与发送继续复用 Hermes 及现有通道。

上游模型适配、旧 LangChain/OpenAI 调用、模拟世界奖励、任意记忆文件改写和高频 tick 都不作为运行依赖。正式引入具体代码前再次核对许可证、依赖版本与当前作用域，不把本表当安装清单。
